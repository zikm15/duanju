# Afterglow 第一版使用说明

本版本在 `/workspace/duanju` 云端 Linux 环境开发。原有 `README.md` 保留不变。

## 访问与启动

- 用户首页：`/`，直接进入竖屏视频播放器。
- 发现页：`/discover`。
- 收藏与继续观看：`/library`。
- 会员方案及权限演示：`/membership`。
- 中文后台：`/admin`。

云端已经安装依赖。构建后的演示启动命令是 `npm run preview`，监听 `0.0.0.0:3000`。这不是公网地址；只有配置了公开入口或端口转发，外部浏览器才能访问。当前会话没有 Sites 发布或云端端口发布工具，不能生成真实公网预览链接。

现已在 GitHub `afterglow-v1-preview` 分支准备 Docker 与 Render Blueprint 配置。要创建公网测试网站，请阅读 [公网部署说明](公网部署.md)。公网部署自动生成独立后台密码，不使用下面仅适用于本机演示的公开密码。

后续云端环境恢复时，在仓库内运行：

```bash
bash scripts/install.sh
npm run preview
```

`scripts/install.sh` 使用锁文件安装，npm 缓存放在 `/workspace/.npm-cache`。基础环境需要 Node.js 24+、ffprobe；重新生成演示素材还需要 ffmpeg 和 Chromium。当前云端已全部具备。

本次尝试更新云端环境草稿时，平台返回 `CONFLICT / draft_not_editable`。再次读取仍为原草稿 revision 2，因此新启动配置未确认保存到平台。完整提案已经放在 `docs/cloud-environment-config.json`；原平台草稿仍可能包含“只允许 README”的旧检查脚本。需要从环境设置打开新的配置会话，使用此提案更新安装及启动配置，再保存发布。该限制不影响当前已经运行的网站进程。

开发模式使用 `DEMO_MODE=true npm run dev`。不需要 Windows 安装任何依赖。

## 用户端操作

1. 首页视频默认静音播放。点击音量图标开声；点击视频或播放按钮可暂停。浏览器若阻止自动播放，点击中央播放按钮即可。
2. 手机上在视频画面向上或向下滑动切换短剧。电脑右侧上下箭头也能切换。
3. 点击 **Episodes** 打开选集。**Auto-play next episode** 开启后会按顺序播放下一集，播放到会员集时显示订阅提示。
4. 点击书签保存短剧，在 **My list → Saved stories** 查看。
5. 进度每隔几秒、暂停、切换页面及页面进入后台时保存。**Continue watching** 可继续观看。浏览器必须保留站点 Cookie；当前不提供跨设备账户同步。
6. **Discover** 支持英文标题/剧情搜索、分类筛选、手机双列海报，桌面会增加列数。

## 会员与支付边界

| 身份 | 免费集 | 会员集 | 平台广告 |
| --- | --- | --- | --- |
| Free explorer | 可观看 | 服务端拒绝访问 | 开启广告配置时显示演示广告 |
| Basic | 全部可观看 | 全部可观看 | 显示演示广告 |
| Premium | 全部可观看 | 全部可观看 | 不显示 |

后台设置“前 N 集免费”，按剧集编号判断。0 表示无免费集。该设置由服务端执行，直接请求付费视频地址也会检查权限。

演示模式下，会员页提供 **Try basic in demo** / **Try premium in demo** / **Return to free explorer**。这些按钮仅修改当前浏览器演示权限，不创建支付订单，不扣款，不自动续费。显示的 $6.99 / $10.99 为拟定价格，可在开发时调整。

PayPal 尚未接入，购买按钮禁用。`POST /api/billing/subscribe` 明确返回 `503 BILLING_NOT_CONNECTED`。即使配置支付凭据，当前代码也不会擅自发起付款。后续接入要求见 [PayPal 接入说明](PayPal接入说明.md)。没有金币、单集购买或观看广告解锁会员集。

## 中文后台

演示环境登录密码为 `afterglow-preview`，登录页也有明确提示。这是公开测试密码，不适用于正式运营。

1. 进入 `/admin` 并登录。
2. 点击“创建短剧”，填写英文名称、简介、分类、免费范围，保存后继续上传素材。
3. 封面支持 JPEG / PNG / WebP，最大 10 MB；建议 2:3 竖版。SVG 上传不接受，避免主动内容注入。
4. 视频支持 MP4，必须为 H.264 视频，音频为 AAC 或 MP3，最大 250 MB；建议 9:16。服务端通过 ffprobe 验证，不会自动转码。重复集数会拒绝；可先删除旧集再上传。
5. 列表中可以编辑短剧、免费范围，删除剧集或短剧。删除需要浏览器确认。
6. “广告与订阅”可启停演示广告、调整 1–30 秒展示时长、英文标题、品牌与说明。

广告始终标记 **DEMO AD**，只演示前贴片倒计时，不连接真实广告平台，不计算真实收益。Premium 不显示平台广告。

## 素材、存储与实际功能

- 六部剧的名称、简介和插画是本项目的原创演示内容。
- 每部剧使用一段 12 秒的原创插画运镜 MP4 作为占位素材，多集会重复同一素材。视频真实可解码、可拖动、可连播，但不是完整真人短剧。页面明确标记 **Original demo footage / Concept series**。
- 海报文件在 `public/assets/posters/`，演示 MP4 在 `media/`。`npm run media` 可在云端重新生成缺少的 MP4。
- SQLite 数据库在 `.runtime/afterglow.sqlite`，上传文件在 `.runtime/uploads/`，均被 Git 忽略。迁移必须备份完整 `.runtime/`，包括 SQLite 的 WAL 文件；建议停服后备份。
- SQLite 数据在服务重启后保留。Cookie 会话默认 30 天，登录管理后台的会话为 8 小时；账户过期后匿名收藏和进度不会自动关联新浏览器。
- 删除数据库内容会删除对应关联记录；本版保留已上传文件，尚未实现孤立文件回收、空间配额与对象存储。

## 验证

```bash
npm run build
npm test
npm run test:browser
```

服务端测试使用临时数据库；浏览器测试启动独立的 3101 端口和临时数据库，不修改运行中演示站的数据。测试覆盖直接视频访问权限、HTTP Range、上传验证、后台操作、支付关闭、搜索、收藏、进度、视频播放、自动连播和手机滑动。

浏览器截图与报告保存在 `test-results/`（不提交 Git）。
