# PrimeDrama 第一版使用说明

代码位于 `zikm15/duanju` 的 `afterglow-v1-preview` 分支，保留原仓库内容和旧版截图，未修改 main。品牌更新为 PrimeDrama。全部开发与验证在云端 Linux 完成，不使用 Windows。

## 页面和操作

- **Home**：黑色沉浸播放器，9:16视频画布，UI叠加不压缩画布。默认静音，声音按钮可切换；点视频暂停/播放，底部滑杆定位。上下滑动切剧，电脑右侧箭头切剧。
- **Watch Full Series**：选集、查看免费范围、开关自动连播、关注整部剧。关注的剧进入 Following。
- 右侧点赞、评论、收藏、分享：实际保存到服务端。支持评论回复/点赞、关注评论用户、删除本人评论。分享使用系统分享或复制链接，不支持时显示可选中的链接。
- **Discover**：纯白背景、彩色4:5双列封面、搜索标题或简介、六个分类、下拉刷新和分页滚动加载。当前6部样例加载完即显示结束提示，不重复填充。推荐标签为编辑推荐，不代表真实流量。
- **Inbox**：实际产生的回复、评论点赞、用户关注和系统通知，支持筛选与已读。欢迎消息为系统通知，不伪造他人互动。
- **Profile**：头像字母、昵称、ID、历史、收藏、喜欢；Settings 可编辑昵称和简介、设置连播、进入创作者后台。浏览器会话身份，暂不支持邮箱登录或跨设备同步。

## VIP：以此规则为准

**有 VIP 付费模式，撤回“所有剧集免费”的说明。**

| 身份 | 可观看剧集 | 平台广告 |
| --- | --- | --- |
| 免费用户 | 每剧前 N 集，N 由后台设置 | 配置启用时显示演示广告 |
| Basic VIP | 全部剧集 | 配置启用时显示演示广告 |
| Premium VIP | 全部剧集 | 无平台广告 |

Profile 中的 VIP 卡片及受限剧集提示都可打开会员页。$6.99/$10.99为拟定月价；PayPal未开通，付款按钮禁用，支付接口返回503，不发生扣款或续费。演示模式可用按钮切换模拟会员；非演示环境禁用此接口。无金币、单集购买、看广告解锁付费集。

权限在访问检查、观看进度和视频流三处校验；复制会员视频地址不能绕过免费范围。

## 中文后台

`/admin`：管理短剧、上传封面及视频、设置前 N 集免费、管理集数、配置演示广告。

- 内部演示默认密码 `afterglow-preview`。设置 `ADMIN_PASSWORD` 后必须使用独立密码，页面不显示默认密码；不要把真实密码发到聊天或提交GitHub。
- 封面：JPEG/PNG/WebP，最大10MB，推荐4:5。
- 视频：H.264 MP4，AAC/MP3音频，最大250MB，推荐9:16，不自动转码。
- 广告：可设置开关、1–30秒展示时长和英文文案，无真实广告收益。Premium不显示平台广告。

## 云端启动

```bash
cd /workspace/duanju
bash scripts/install.sh
bash scripts/start-preview.sh
npm test
npm run test:browser
```

`npm run build` 执行类型检查及生产构建；`npm run media` 使用原创新海报制作12秒无音轨演示视频，需 Chromium 和 ffmpeg。当前6部剧、41条集数记录，同剧不同集复用一段样片，不是真实完整短剧。

SQLite、上传和日志保存在 `.runtime/`，不会提交GitHub。旧数据库名 `afterglow.sqlite` 和 cookie 名为兼容保留。更新只替换未修改过的内置样例封面；不覆盖上传封面、改过的剧名或免费范围。

云端会话可能回到初始快照；从已推送的预览分支恢复，详见 [启动技能](../skills/primedrama-cloud-start/SKILL.md)。真实影视内容需使用授权素材。
